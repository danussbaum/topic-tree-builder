# UC-33 Handlungsvorlage löschen

## Trigger
Der Benutzer klickt bei einer geöffneten Handlungsvorlage auf «Löschen».

## Pre-Condition
- Keine

## Postcondition
- Die Handlungsvorlage existiert nicht mehr; bestehende Handlungen bleiben unverändert.

## Main Path
1. Der Benutzer klickt auf «Löschen».
2. Das System löscht die Handlungsvorlage ohne Rückfrage.

## Alternative Paths
Keine
