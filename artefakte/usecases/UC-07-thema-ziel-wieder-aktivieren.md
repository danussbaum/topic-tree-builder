# UC-07 Thema / Ziel wieder aktivieren

## Trigger
Der Benutzer klickt bei einem abgeschlossenen Thema / Ziel auf «Thema / Ziel wieder aktivieren».

## Pre-Condition
- Das Thema / Ziel hat den Status 'Abgeschlossen'.

## Postcondition
- Das Thema / Ziel hat kein Gültig bis und den Status 'Aktiv'.
- Eine bestehende Zielbeurteilung bleibt erhalten.

## Main Path
1. Der Benutzer klickt auf «Thema / Ziel wieder aktivieren».
2. Das System entfernt Gültig bis ohne Rückfrage und setzt den Status auf 'Aktiv'.

## Alternative Paths
Keine
