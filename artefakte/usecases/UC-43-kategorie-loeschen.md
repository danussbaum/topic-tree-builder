# UC-43 Kategorie löschen

## Trigger
Der Benutzer klickt in Einstellungen › Kategorien bei einer Kategorie auf das Löschen-Symbol.

## Pre-Condition
- Keine

## Postcondition
- Die Kategorie existiert nicht mehr; Verweise in Disziplinen und Handlungsvorlagen sind entfernt.

## Main Path
1. Der Benutzer klickt auf Löschen.
2. Das System löscht die Kategorie ohne Rückfrage und entfernt Verweise darauf.

## Alternative Paths
Keine
