# UC-39 Hilfsmittel löschen

## Trigger
Der Benutzer klickt bei einem geöffneten Hilfsmittel auf «Löschen».

## Pre-Condition
- Keine

## Postcondition
- Das Hilfsmittel existiert nicht mehr; Verweise darauf sind entfernt.

## Main Path
1. Der Benutzer klickt auf «Löschen».
2. Das System löscht das Hilfsmittel ohne Rückfrage.

## Alternative Paths
Keine
