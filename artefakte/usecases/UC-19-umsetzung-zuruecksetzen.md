# UC-19 Umsetzung zurücksetzen

## Trigger
Der Benutzer klickt im Dialog einer bestätigten oder verschobenen Handlung auf «Zurücksetzen».

## Pre-Condition
- Thema / Ziel aktiv

## Postcondition
- Die Umsetzung hat den Status 'Offen'; Bestätigungs- und Verschiebungsangaben sind gelöscht.

## Main Path
1. Der Benutzer klickt auf «Zurücksetzen».
2. Das System löscht die Umsetzungsangaben inklusive Verschiebung und setzt den Status auf 'Offen'.

## Alternative Paths
Keine
