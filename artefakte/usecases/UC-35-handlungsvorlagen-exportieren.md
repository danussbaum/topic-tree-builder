# UC-35 Handlungsvorlagen exportieren

## Trigger
Der Benutzer klickt in Einstellungen › Handlungsvorlagen auf «Export».

## Pre-Condition
- Keine

## Postcondition
- Eine CSV-Datei mit allen Handlungsvorlagen inklusive «veränderbar»/«zwingend» je Feld liegt vor.

## Main Path
1. Der Benutzer klickt auf «Export».
2. Das System erstellt die Datei in der angezeigten Sortierung.

## Alternative Paths
Keine
