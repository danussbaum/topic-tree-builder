# UC-42 Kategorie erstellen

## Trigger
Der Benutzer erfasst in Einstellungen › Kategorien Code und Bezeichnung.

## Pre-Condition
- Keine

## Postcondition
- Die Kategorie existiert.

## Main Path
1. Der Benutzer erfasst Code und Bezeichnung und klickt auf «Erstellen».
2. Das System speichert die Kategorie.

## Alternative Paths
**1a. Bezeichnung ist leer**
1. Das System lässt «Erstellen» nicht zu.
2. Weiter bei Schritt 1.
