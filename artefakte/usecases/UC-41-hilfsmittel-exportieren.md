# UC-41 Hilfsmittel exportieren

## Trigger
Der Benutzer klickt in Einstellungen › Hilfsmittel auf «Export».

## Pre-Condition
- Keine

## Postcondition
- Eine CSV-Datei mit allen Hilfsmitteln liegt vor.

## Main Path
1. Der Benutzer klickt auf «Export».
2. Das System erstellt die Datei.

## Alternative Paths
Keine
