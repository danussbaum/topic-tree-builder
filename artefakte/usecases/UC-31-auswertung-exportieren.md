# UC-31 Auswertung exportieren

## Trigger
Der Benutzer klickt in den Auswertungen auf «Export».

## Pre-Condition
- Mindestens eine Klient/in ist ausgewählt.

## Postcondition
- Eine Excel-Datei «Auswertung» bzw. «Resultat und Beobachtung» des Monats liegt vor.

## Main Path
1. Der Benutzer klickt auf «Export».
2. Das System erstellt die Datei mit den angezeigten Umsetzungen.

## Alternative Paths
Keine
