# UC-29 Evaluation exportieren

## Trigger
Der Benutzer klickt in der Evaluation auf «Export».

## Pre-Condition
- Mindestens eine Klient/in ist ausgewählt.

## Postcondition
- Eine Excel-Datei «Evaluation» mit allen abgeschlossenen Themen / Zielen und ihren Zielbeurteilungen liegt vor.

## Main Path
1. Der Benutzer klickt auf «Export».
2. Das System erstellt die Datei.

## Alternative Paths
**1a. Keine Klient/in ist ausgewählt**
1. Das System lässt den Export nicht zu.
2. Use Case endet.
