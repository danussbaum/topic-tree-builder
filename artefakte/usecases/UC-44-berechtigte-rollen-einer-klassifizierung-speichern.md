# UC-44 Berechtigte Rollen einer Klassifizierung speichern

## Trigger
Der Benutzer klickt in Einstellungen › Klassifizierungen auf eine Klassifizierung.

## Pre-Condition
- Keine

## Postcondition
- Die Klassifizierung hat die gewählten berechtigten Rollen.

## Main Path
1. Der Benutzer wählt die berechtigten Rollen und klickt auf «Speichern».
2. Das System speichert die Zuordnung.

## Alternative Paths
**1a. Der Benutzer klickt auf «Abbrechen»**
1. Das System verwirft die Änderung.
2. Use Case endet.
