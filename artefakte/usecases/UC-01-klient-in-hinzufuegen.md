# UC-01 Klient/in hinzufügen

## Trigger
Der Benutzer klickt in der Navigation bei «Klient/innen» auf «+» (Neue Klient/in hinzufügen).

## Pre-Condition
- Keine

## Postcondition
- Eine neue Klient/in mit Vorname «Neu» und Nachname «Klient/in» existiert und ist ausgewählt.

## Main Path
1. Der Benutzer klickt auf «+».
2. Das System legt eine Klient/in ohne Themen / Ziele an, vergibt die Laufnummer und wählt sie aus.

## Alternative Paths
Keine
